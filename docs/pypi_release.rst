PyPI Release Guide
==================

PyPI publishing for this project is automated through GitHub Actions and PyPI
Trusted Publishing. Do not use token-based manual uploads for normal releases.

The canonical maintainer runbook is
`docs/release-process.md <https://github.com/monocongo/climate_indices/blob/main/docs/release-process.md>`__.
